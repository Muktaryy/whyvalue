Session Management

why.watch(snapshot=False)

Signature: why.watch(snapshot: bool = False) -> WatchSession

Purpose: Starts a WhyValue provenance tracking session. Clears event history, enables pandas instrumentation, and returns a WatchSession context manager.

  • Parameters: snapshot (bool, default False) — When True, captures before/after state snapshots for operations like fillna.
  • Return Value: WatchSession context manager object.
  • Exceptions: None. If called while already watching, increments watch depth and prints "WhyValue is already watching.".
  • v0.2 Limitation: Session state is global; concurrent sessions across multiple threads are not isolated in v0.2.
Example
with why.watch(snapshot=True):
    df["col"] = df["col"].fillna(0)

why.stop(force=True)

Signature: why.stop(force: bool = True) -> None

Purpose: Stops the active WhyValue watch session and unregisters pandas adapter instrumentation.

  • Parameters: force (bool, default True) — If False and watch depth > 1, decrements watch depth without stopping immediately.
  • Return Value: None.
  • Exceptions: None. Prints "WhyValue is not currently watching." if called when not watching.

why.is_watching()

Signature: why.is_watching() -> bool

Purpose: Checks whether a WhyValue watch session is currently active.

  • Parameters: None.
  • Return Value: bool — True if watching, False otherwise.

WatchSession

Signature: class WatchSession(snapshot: bool = False)

Purpose: Context manager class returned by why.watch(). Automatically invokes why.stop(force=False) on exit.

Tracking & Explanation

why.track(obj)

Signature: why.track(obj: Union[list, dict]) -> Union[TrackedList, TrackedDict]

Purpose: Wraps a native Python list or dictionary in a provenance-tracked container (TrackedList or TrackedDict).

  • Parameters: obj (list or dict) — Raw Python container to track.
  • Return Value: TrackedList or TrackedDict instance.
  • Exceptions:
    • RuntimeError: If called outside an active why.watch() session.
    • TypeError: If obj is not a list or dictionary.
  • v0.2 Limitation: Custom classes, sets, and tuples are not supported by why.track() in v0.2.
Example
with why.watch():
    data = why.track([10, 20])
    data.append(30)

why.explain(obj, row=None, column=None, mode=None, key=None, index=None)

Signature: why.explain(obj, row=None, column=None, mode="full", key=None, index=None)

Purpose: Explains why a target cell in a pandas DataFrame, key in a TrackedDict, or index in a TrackedList has its current value.

  • Parameters:
    • obj: Target pandas DataFrame, Series, TrackedDict, or TrackedList.
    • row: 0-indexed row position for DataFrame, key for TrackedDict, or index for TrackedList.
    • column: Target column name for DataFrame.
    • mode (str, default "full"): Output format — "full", "short", or "json".
    • key: Key name for TrackedDict (optional fallback).
    • index: Index number for TrackedList (optional fallback).
  • Return Value:
    • mode="full": Prints human-readable multi-line trace to stdout; returns None.
    • mode="short": Prints and returns a concise single-line summary str.
    • mode="json": Returns a structured Python dict containing event DAG and metadata.
  • Exceptions: ValueError if mode is not "full", "short", or "json".
Example
why.explain(df, row=0, column="revenue", mode="full")

why.explain_removed(obj=None, row=None)

Signature: why.explain_removed(obj=None, row=None)

Purpose: Explains why a row was excluded from a DataFrame by a boolean filter condition (>, <, &, |) or dropna() step.

  • Parameters: obj (DataFrame, optional), row (int, required 0-indexed row position).
  • Return Value: None (prints explanation to stdout).

why.trace(obj)

Signature: why.trace(obj: pd.DataFrame) -> None

Purpose: Prints all recorded transformation events belonging to the specified DataFrame in chronological order.

Data Sources

why.load_json(path, encoding="utf-8")

Signature: why.load_json(path: Union[str, Path], encoding: str = "utf-8") -> Union[TrackedDict, TrackedList]

Purpose: Loads a JSON file into nested TrackedDict and TrackedList containers with attached JSON path metadata ($, $.key, $[0]).

  • Watch Requirement: Must be called inside an active why.watch() session (raises RuntimeError if inactive).
  • Metadata Captured: source_type="json", source_path, json_path.
  • Native Errors: FileNotFoundError, json.JSONDecodeError, UnicodeDecodeError propagate natively.

why.load_csv(path, encoding="utf-8", delimiter=",")

Signature: why.load_csv(path: Union[str, Path], encoding: str = "utf-8", delimiter: str = ",") -> TrackedList

Purpose: Loads a CSV file into a TrackedList of TrackedDict rows with 1-based data row coordinates (Row 1 = first row below header).

  • Watch Requirement: Requires active why.watch() context (raises RuntimeError if inactive).
  • Metadata Captured: source_type="csv", source_path, csv_row, delimiter, encoding.
  • Note: All CSV field values are initially loaded as strings.

why.load_txt(path, encoding="utf-8", keepends=False)

Signature: why.load_txt(path: Union[str, Path], encoding: str = "utf-8", keepends: bool = False) -> TrackedList

Purpose: Loads a text file into a TrackedList of string lines with 1-based line provenance metadata.

  • Watch Requirement: Requires active why.watch() context.
  • Metadata Captured: source_type="txt", source_path, line_count, 1-based line numbers.

why.get(url, **kwargs)

Signature: why.get(url: str, **kwargs) -> TrackedResponse

Purpose: Performs an HTTP GET request using requests.get() and wraps the response in a TrackedResponse. Calling .json() on the response returns a provenance-tracked container linked to the HTTP request.

  • Watch Requirement: Requires active why.watch() context (raises RuntimeError if inactive).
  • Metadata Captured: source_type="http", method="GET", url (sanitized), requested_url (sanitized), status_code, content_type, json_path.
  • Security Behavior: Query parameters and basic-auth credentials in URLs are automatically sanitized (e.g. token=secret → token=REDACTED). Headers, cookies, and request bodies are not recorded in provenance events.
  • Scope Note: v0.2 provides the explicit why.get() helper rather than globally intercepting all requests module calls.

Pandas Bridge

why.to_dataframe(data)

Signature: why.to_dataframe(data: Union[TrackedList, TrackedDict]) -> pd.DataFrame

Purpose: Converts a TrackedList or TrackedDict container into a pandas DataFrame while preserving upstream source lineage.

  • Input Types: TrackedList or TrackedDict (raises TypeError if passed raw untracked lists or dicts).
  • Return Type: pd.DataFrame.
  • Watch Requirement: Requires active why.watch() context (raises RuntimeError if inactive).
  • Identity & Metadata: Generates a fresh unique _whyvalue_id and copies _whyvalue_source metadata into df.attrs.

Mode Return Value Console Output Primary Purpose
full None Multi-line formatted text Interactive debugging with complete step-by-step origin and transformation history.
short str Single-line summary string Quick logs, inline assertions, or concise summary checks.
json dict (Python dictionary) None Programmatic inspection, automated audit logging, CI test assertions, and structured reports.
