Tracked Lists

Standard Python list objects do not store provenance history. WhyValue uses a lightweight, compliant list subclass named TrackedList to record list operations while watching.

Why Use Tracked Lists?

When you wrap a list with why.track(), WhyValue records list mutations (such as append(), insert(), or element reassignments) into the active session history so you can trace how the list evolved.

tracked_list_example.py 
import whyvalue as why

with why.watch():
    items = why.track([10, 20, 30])
    items.append(40)

    why.explain(items)

Representative output:

Console Output 
Why is this list [10, 20, 30, 40]?

Transformation history:

1. Created list [10, 20, 30]
2. append(40)

Final:
[10, 20, 30, 40]

Supported List Operations

TrackedList remains 100% compatible with normal Python list operations (isinstance(items, list) == True). The following list operations are recorded into provenance history:

Operation Tracked Status Description
append(value) Yes Appends an element to the end of the list.
extend(iterable) Yes Extends list by appending elements from an iterable.
insert(index, value) Yes Inserts an element at a specified index.
remove(value) Yes Removes the first occurrence of a value.
pop(index=-1) Yes Removes and returns an item at index (default last).
clear() Yes Removes all elements from the list.
items[index] = value Yes Item assignment at index (__setitem__).
del items[index] Yes Deletes an item at index (__delitem__).

Requirements for why.track()

Active Watch Required: Calling why.track() outside of an active watch session raises a RuntimeError("why.track() requires an active WhyValue watch session.").

Currently, why.track() supports native Python list and dict objects. Attempting to track unsupported types raises a TypeError.

Explaining Specific List Elements

Pass an integer index to inspect provenance for a specific list index. Negative indices (e.g. index=-1) are supported and resolved relative to the list length.

Index Explanation 
why.explain(items, index=1)
why.explain(items, index=-1)

For complete details on output formats (mode="full", mode="short", mode="json"), see the explain() Documentation.

List Mutations with Snapshots

To capture historical before/after list states across mutations, pass snapshot=True to why.watch():

List Snapshot Example 
with why.watch(snapshot=True):
    items = why.track([10, 20])
    items.append(30)

    res = why.explain(items, mode="json")
    print(res["steps"][0]["before"])  # [10, 20]
    print(res["steps"][0]["after"])   # [10, 20, 30]

Learn more about historical state memory trade-offs in Snapshots Documentation.
