Pandas Integration

WhyValue does not replace pandas. You write standard, idiomatic pandas code, while WhyValue observes supported operations during an active watch session.

Mental Model

pandas operation  →  provenance event  →  final value  →  why.explain()

Basic Example

pandas_basic.py 
import pandas as pd
import whyvalue as why

df = pd.DataFrame({
    "price": [100, 200],
    "quantity": [2, 3]
})

with why.watch():
    df["total"] = df["price"] * df["quantity"]

    why.explain(df, row=1, column="total")

Representative output:

Console Output 
Why is total = 600?

price = 200
quantity = 3

200 × 3
→ total = 600

Supported Operations in v0.2

Category Supported Operations Notes & Scope
Arithmetic +, -, *, / Column vs Column, Column vs Scalar, and reverse scalar operations (e.g. 100 / df["col"]).
Filtering >, >=, <, <=, ==, !=, &, | Comparison filters and combined boolean conditions. Use explain_removed() to explain why rows disappeared.
Missing Data fillna(), dropna(subset=[...]) fillna attaches before/after state when snapshot=True. dropna records removed rows for target subset columns.
Transformations astype(), round(), rename(), map(), apply() map() supports dictionary mappings. apply() tracks function names/labels (e.g. <lambda> or func.__name__).
Merge DataFrame.merge() Basic merge tracking (records left/right DataFrame identity, how, and on keys).
GroupBy SeriesGroupBy: sum(), mean(), count(), min(), max() Targeted SeriesGroupBy aggregations on a single column (e.g. df.groupby("cat")["sales"].sum()).

Explaining Values & Sequential History

Call why.explain(df, row, column) to inspect why a value exists. row is the 0-indexed row position in the DataFrame, and column is the target column name.

When a column undergoes multiple sequential transformations (e.g. fillna(0) → astype(float) → round(1)), WhyValue prints the chronological event chain:

Sequential History Example 
with why.watch():
    df["val"] = df["val"].fillna(0)
    df["val"] = df["val"].astype(float)
    df["val"] = df["val"].round(1)

    why.explain(df, row=0, column="val")

Explaining Removed Rows (explain_removed)

To understand why a row was excluded by a dropna() step or boolean filter condition, use why.explain_removed(df, row):

explain_removed_example.py 
with why.watch():
    df = pd.DataFrame({"age": [17, 20, 30], "salary": [5000, 2500, 4500]})
    df = df[(df["age"] >= 18) & (df["salary"] > 3000)]

    why.explain_removed(df, row=1)

Output printed to console:

Why was row 1 removed?

Combined filter (AND):

age >= 18
salary > 3000

Row removed because the row did not satisfy all conditions.

GroupBy & Merge

For SeriesGroupBy aggregations (e.g. res = df.groupby("category")["sales"].sum()), call why.explain(res, row="A") to inspect the aggregation function and grouping key value. For DataFrame merges, why.explain(res, row=0, column="col") details the join type (`left`, `inner`, etc.) and key names.
