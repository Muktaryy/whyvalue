JSON Provenance

Loading JSON data through why.load_json() preserves origin information, attaching the source file path and JSON path directly to tracked container objects.

Why Use why.load_json()?

Standard json.load() produces un-tracked Python dicts and lists. why.load_json() recursively converts JSON objects into TrackedDict and JSON arrays into TrackedList, preserving full JSON path lineage.

Example file users.json:

users.json 
{
  "users": [
    {
      "name": "Ali",
      "age": 21
    }
  ]
}

Python script:

load_json_example.py 
import whyvalue as why

with why.watch():
    data = why.load_json("users.json")
    user = data["users"][0]

    why.explain(user, key="name")

Mental Model

users.json  →  $.users[0].name  →  "Ali"

Return Types

  • JSON Objects ({}) → Converted to TrackedDict.
  • JSON Arrays ([]) → Converted to TrackedList.
  • Primitive Values (strings, numbers, booleans, null) → Remain standard Python primitive values inside tracked containers.

JSON Path Notation

WhyValue constructs JSON paths starting at root $:

  • $ (Root container)
  • $.users (Property access)
  • $.users[0] (Array index access)
  • $.users[0].name (Nested property access)
  • Keys containing spaces or special characters use safe bracket notation, e.g. $["user.name"]

Error Handling

Standard file and decoding errors (such as FileNotFoundError, json.JSONDecodeError, or UnicodeDecodeError) propagate natively without being swallowed by WhyValue.
