Getting Started with WhyValue

WhyValue enables lightweight, non-invasive provenance tracking for Python containers, data files, HTTP responses, and pandas DataFrames.

1. Installation

Install WhyValue from PyPI using pip:

$ pip install whyvalue

WhyValue requires Python 3.10 or higher and pandas 2.0+.

2. Import

Import WhyValue in your Python script or notebook:

script.py 
import whyvalue as why

3. First Example

Track a Python dictionary and explain why a specific key has its value:

quick_start.py 
import whyvalue as why

with why.watch():
    user = why.track({"name": "Ali", "age": 20})
    user["age"] = 21

    why.explain(user, key="age")

4. Watching Data

WhyValue records provenance only when a watch session is active. You can start and stop watching manually:

Manual Session
why.watch()

# Your data operations here...

why.stop()

Preferred Context-Manager Usage

The recommended pattern is using a with context manager, which automatically stops tracking when exiting the block:

Context Manager
with why.watch():
    user = why.track({"status": "active"})
    user["status"] = "verified"

5. Enabling Snapshots

By default, WhyValue tracks operation metadata without deep-copying full container states. When you want to record full historical state snapshots before and after each mutation, pass snapshot=True:

Snapshots Session
with why.watch(snapshot=True):
    items = why.track([10, 20])
    items.append(30)

    why.explain(items)
Memory Consideration
Enabling snapshots creates deep copies of tracked structures during mutations. Use snapshot=True during debugging or for critical audit sessions.

6. Explanation Modes

why.explain() supports three output modes depending on your workflow:

1. Default / Full Mode (Human-Readable)

Outputs formatted step-by-step history to standard stdout:

why.explain(user, key="age", mode="full")

2. Short Mode (Concise Summary)

Prints a single-line summary string suitable for logging:

why.explain(user, key="age", mode="short")

3. JSON Mode (Programmatic API)

Returns a structured dictionary without printing, ideal for automated test assertions or data pipeline reporting:

info = why.explain(user, key="age", mode="json")
print(info["final_value"])  # 21

7. Where to Go Next

Now that you know the basics, explore WhyValue's core tracking capabilities:

  • Python Containers: Track native list and dict mutations with why.track().
  • Data Loaders: Ingest JSON (why.load_json()), CSV (why.load_csv()), and TXT files (why.load_txt()).
  • HTTP APIs: Wrap GET requests with why.get() for REST API provenance.
  • pandas Integration: Bridge tracked data into DataFrames using why.to_dataframe() for end-to-end lineage.
