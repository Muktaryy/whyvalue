Installation

WhyValue is a developer-first Python library for data provenance and transformation tracking across Python containers, files, HTTP APIs, and pandas.

Primary Installation

Install WhyValue directly from PyPI using pip:

$ pip install whyvalue

Alternatively, run via python module syntax:

$ python -m pip install whyvalue

Requirements

WhyValue requires the following runtime environment:

  • Python: >= 3.10
  • pandas: >= 2.0
  • requests: >= 2.31

Verify Installation

You can verify that WhyValue is correctly installed by running a short test in your terminal or Python REPL:

test_install.py 
import whyvalue as why

print("WhyValue installed")

Upgrade

To upgrade an existing installation to the latest version of WhyValue:

$ pip install --upgrade whyvalue
