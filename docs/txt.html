TXT Provenance

The why.load_txt() function loads text files into a TrackedList containing standard Python strings, preserving 1-based line number provenance.

Function Signature

Signature 
why.load_txt(path, encoding="utf-8", keepends=False)

Example file notes.txt:

notes.txt 
Python is useful.
SQL is useful.
Data engineering is fun.

Python script:

load_txt_example.py 
import whyvalue as why

with why.watch():
    lines = why.load_txt("notes.txt")

    why.explain(lines, index=1)

Mental Model

lines[1]  →  notes.txt  →  line 2  →  "SQL is useful."

No TrackedString in v0.2

Return Type: why.load_txt() returns a TrackedList containing ordinary Python str elements. There is intentionally no TrackedString wrapper class in WhyValue v0.2.

Line Ending Options (keepends)

  • keepends=False (Default): Strips newline characters using standard Python splitlines().
  • keepends=True: Retains trailing line separators (e.g. \n or \r\n).
  • Blank lines and empty files return an empty or single-element list corresponding to standard splitlines() semantics.

Subsequent List Mutations

Modifying line elements (e.g. lines[1] = "SQL is very useful.") updates the container using standard TrackedList provenance:

Line Mutation 
with why.watch():
    lines = why.load_txt("notes.txt")
    lines[1] = "SQL is very useful."

    why.explain(lines, index=1)
