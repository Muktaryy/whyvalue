trace()

The why.trace() function provides an overview of the transformation history belonging to a pandas DataFrame.

Distinction:
• trace(df) → displays WHAT transformation events occurred across a DataFrame.
• explain(df, row, col) → explains WHY a specific cell has its value.

Usage Example

trace_example.py 
import pandas as pd
import whyvalue as why

with why.watch():
    df = pd.DataFrame({"price": [100, 200], "tax": [10, 20]})
    df["total"] = df["price"] + df["tax"]

    why.trace(df)

Output printed to console:

Console Output 
WhyValue Trace

total = price + tax

When Should I Use trace()?

  • To inspect the chronological sequence of column creations and transformations across a DataFrame.
  • To verify which operations WhyValue observed during the active watch session.
  • To get a high-level summary of DataFrame operations before drilling down into a specific cell with why.explain().

Behavior Notes

If no transformations have been recorded for the DataFrame, calling why.trace(df) prints "No transformations recorded." and returns None.

Note: WhyValue v0.2 outputs text-based trace summaries to stdout. It does not generate a graphical node diagram or web-based DAG UI.
