Snapshots

By default, WhyValue operates in lightweight mode (snapshot=False), recording operation types and structural metadata without copying full historical data structures.

Why Snapshots Exist

Standard provenance tracking notes which operations occurred (for example, a fillna() call or dictionary key update), but does not copy the entire historical object state at every step. Enabling snapshots instructs WhyValue to capture deep-copied historical state before and after supported mutations.

Enabling Snapshots

Pass snapshot=True to why.watch() or the context manager:

Snapshot Context Manager 
import whyvalue as why

with why.watch(snapshot=True):
    user = why.track({"status": "pending"})
    user["status"] = "active"

    # Historical before/after values are preserved in explain()
    res = why.explain(user, key="status", mode="json")
    print(res["steps"][0]["before"])  # 'pending'
    print(res["steps"][0]["after"])   # 'active'

Current Support Scope

  • TrackedList & TrackedDict: Captures before and after value snapshots during mutations (e.g. __setitem__, update(), append()).
  • pandas DataFrames: Snapshot capture is intentionally targeted (for example, capturing original Series state prior to fillna() operations).
Memory Warning:
snapshot=True is useful when you need historical before/after value inspection, but it can increase memory usage for large data structures because WhyValue creates value copies during mutations.
