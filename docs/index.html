WhyValue

ASK YOUR DATA WHY

Track the journey. Trace the changes. Explain every value.

WhyValue is a developer-first Python library for tracking data transformations and explaining why values have the values they do across Python containers, files, HTTP APIs, and pandas.

Get Started View on GitHub
$ pip install whyvalue

Why WhyValue?

In traditional data pipelines and analytical scripts, you can inspect final values:

Python
total = 600

But when debugging unexpected data issues, engineers need to answer:

  • Where did 600 come from? Which raw row or file line generated it?
  • Which values produced it? Did a filter or fillna alter the calculation?
  • Which transformations changed it? What step modified the field in transit?
  • Did the value originate from CSV, JSON, or an HTTP API? Where is the true source of truth?

WhyValue preserves that journey automatically without invasively altering standard Python or pandas APIs.

Core Example

WhyValue follows data lineage across library and format boundaries — from raw files into tracked containers and pandas DataFrames:

example.py 
import whyvalue as why

with why.watch(snapshot=True):
    data = why.load_csv("sales.csv")
    df = why.to_dataframe(data)

    df["total"] = df["price"] * df["quantity"]

    why.explain(df, row=0, column="total")

Supported in v0.2

WhyValue v0.2 includes full provenance tracking across these feature areas:

🐍
Python Lists & Dicts
Track mutation history (`append`, `pop`, `setitem`) with `TrackedList` and `TrackedDict`.
📄
JSON, CSV & TXT
Load files with precise source origin tracking (file paths, row numbers, line counts, JSON paths).
🌐
HTTP APIs
Capture REST API response lineage with automatic credential and query param redaction.
🐼
pandas Operations
Track column arithmetic, `fillna`, `astype`, filtering, groupbys, and merges.
🔗
Cross-Source Lineage
Bridge files and API data seamlessly into DataFrames using `why.to_dataframe()`.
🔍
Flexible Explanations
Inspect lineage in `full` human-readable, `short` summary, or `json` programmatic modes.
